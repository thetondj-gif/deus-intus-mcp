# Privacy

This repository is a public distribution wrapper for the remote Deus Intus capability service.

The wrapper itself does not contain founder credentials, private customer data, or service secrets. Requests sent through the configured MCP endpoint are handled by the remote service under the permissions and authentication available to the connected user or tenant.

Do not commit access tokens, OAuth credentials, API keys, service-role keys, private data, or local runtime state to this repository.

For account-specific data handling questions, use the support/contact route published by the Deus Intus service.
